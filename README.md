# ⌨️ TypeSpeed - Minimal Typing Speed Test

A beautiful, fast and distraction-free typing test inspired by Monkeytype. Built with **pure HTML, CSS & Vanilla JavaScript** - no frameworks, no dependencies.



---

### ✨ Features

- 🚀 **Instant Start** - Just start typing, no click needed
- ⏱️ **Time Modes:** 15s / 30s / 60s
- 📝 **Modes:** Common words + Quotes
- 🎯 **Live Stats:** WPM, Accuracy, Time left
- 🎨 **Premium UI:** JetBrains Mono, glassmorphism, blinking caret, word highlighting
- ↩️ **Smart Backspace:** Jump back to fix incorrect words
- 📱 Fully responsive
- ⚡ Zero dependencies
